## 📊 Dataset

The dataset used in this project is the **Airbnb Listings & Reviews** dataset
provided by Maven Analytics.

- **Source:** Maven Analytics Data Playground
- **Original Source:** Inside Airbnb
- **License:** Public Domain
- **Coverage:** 250K+ Airbnb listings and 5M+ historical reviews

🔗 **[View Dataset →](https://mavenanalytics.io/data-playground/airbnb-listings-reviews)**
